# دفتر بيتي

نموذج تفاعلي لتطبيق آيفون وآيباد يساعد المالك على توثيق كل ما يخص بناء بيته: المصروفات، المقاولين، العمالة اليومية، التمويل، المعاملات الحكومية، اختيارات التصميم، اليوميات والصور، من الحفر حتى تسليم المفتاح.

- يفتح على الجوال بملء الشاشة كتطبيق.
- على الكمبيوتر يعرض إطار آيفون وآيباد مع إمكانية التبديل بينهما.

جميع الأسماء والمبالغ بيانات تجريبية.
